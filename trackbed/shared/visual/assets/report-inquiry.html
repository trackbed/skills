Do agencies finish onboarding, or stop at the import step?

Prompted by docs/strategy.md:41

If most agencies stop at the import step, the next two quarters of the roadmap polish a product that few accounts ever reach.

What prompted it

The strategy says "onboarding is solved", but the import step has had no change in eight months and no event is recorded when it completes.

The uncomfortable answer

Most trial accounts never import a project, so they never see the board.

How to find out

Count trial accounts created in the last 90 days that have at least one imported project. Half a day.

What would settle it

Above 60 percent, onboarding is not the problem. Below 30 percent, it is the first thing to fix.

Investigation prompt

Using the production read replica, count trial accounts created in the
last 90 days and how many have at least one imported project. Report the
ratio by signup week.
