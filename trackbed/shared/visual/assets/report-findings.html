Critical issues

Export route reads the tenant ID from the query string

src/routes/export.ts:42

Any signed-in user can download another tenant's rows by changing ?tenant= in the URL, because the route never checks the value against the session.

Evidence

const rows = await exportRows(req.query.tenant);

This runs before any ownership check, and req.session.tenantId is never read.

Suggested fix

Take the tenant from req.session.tenantId and reject a mismatching query value with 403, as src/routes/board.ts:31 already does.

Retry helper returns undefined after its last attempt fails

src/lib/retry.ts:18-31

When every attempt fails, callers receive undefined and cannot tell an exhausted retry from an empty result, so a failed save looks like a successful one.

Evidence

} catch (error) {

Suggested fix
